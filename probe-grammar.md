# Grammar probe

As defined in [rule 2.a](#rule-2), and see [rule 49c](#rule-49).

<a id="rule-1"></a>
```
1. expression =
   a. boxed expression |
   b. textual expression ;
```
<a id="rule-2"></a>
```
2. textual expression =
   a. for expression | if expression | quantified expression |
   b. disjunction |
   c. conjunction ;
```
<a id="rule-49"></a>
```
49. literal = simple literal | "null" ;
```
